## アプリケーション概要

### アプリケーション名
**Alphaus MSP Revenue Simulator (compare-risp)**

### 目的
AWS Managed Service Provider (MSP) 向けに、保険型Reserved Instance/Savings Plan（保険RI/SP）と標準RI/SPのコスト最適化を行うシミュレーションツール。最適な購入戦略を提案し、収益性を可視化する。

### 対象ユーザー
- **主要ユーザー**: MSPの営業担当者、技術担当者
- **副次ユーザー**: MSPの顧客（エンドユーザー）
- **想定利用シーン**: 
  - 顧客へのコスト削減提案
  - 社内での収益シミュレーション
  - 価格見積もり作成

### 1. リソース選択機能

**機能ID**: `FR-001`  
**機能名**: 動的AWSリソース選択

**ユーザーストーリー:**
> 営業担当者として、顧客のAWS環境に合わせて、複数のAWSサービスとインスタンスタイプを選択し、数量を設定したい。

**詳細機能:**
- ✅ **サービス選択**: EC2, RDS, ElastiCacheから選択
- ✅ **インスタンスタイプ選択**: サービスごとに利用可能なインスタンスタイプを動的に表示
  - EC2: t3.micro, t3.small, t3.medium, t3.large, t3.xlarge, t3.2xlarge, c5シリーズ（12種類）
  - RDS: db.t3.micro, db.t3.small, db.t3.medium, db.r5.large, db.r5.xlarge, db.r5.2xlarge（6種類）
  - ElastiCache: cache.t3.micro, cache.t3.small, cache.r5.large（3種類）
- ✅ **数量設定**: リソースごとに数量を入力（1〜100）
- ✅ **リソースの追加・削除**: 複数のリソースを追加・削除可能
- ✅ **SVGアイコン表示**: 各サービスをSVGアイコンで表示（視認性向上）

**操作フロー:**
```
1. "リソースを追加" ボタンをクリック
2. サービスを選択（EC2, RDS, ElastiCache）
3. インスタンスタイプを選択（動的にフィルタリングされる）
4. 数量を入力
5. （オプション）さらにリソースを追加
6. 不要なリソースは "削除" ボタンで削除
```

**入力制約:**
- 数量: 1以上の整数
- 最大リソース数: 制限なし（実用上は10〜20リソース推奨）

### 2. シミュレーション設定機能

**機能ID**: `FR-002`  
**機能名**: コスト最適化パラメータ設定

**ユーザーストーリー:**
> 営業担当者として、顧客の利用状況に合わせて、保険プラン、標準プラン、カバレッジ、使用率を設定したい。

**詳細機能:**
- ✅ **保険プラン選択**: 30日保証 / 1年保証
  - 30日保証: 割引率30%、保険料率10%
  - 1年保証: 割引率35%、保険料率5%
- ✅ **標準プラン選択**: 契約期間と支払方法の組み合わせ
  - 契約期間: 1年 / 3年
  - 支払方法: NoUpfront / PartialUpfront / AllUpfront / SavingsPlan
- ✅ **カバレッジ設定**: 0〜100%（スライダーで設定）
  - カバレッジ: リソース全体のうち、RI/SPでカバーする割合
- ✅ **使用率設定**: 0〜100%（スライダーで設定）
  - 使用率: 実際に稼働している時間の割合（例: 80% = 月730時間中584時間稼働）
- ✅ **割引率情報モーダル**: 各プランの割引率、保険料率、実効割引率を確認可能

**操作フロー:**
```
1. 保険プランを選択（ラジオボタン）
2. 標準プランを選択（契約期間 + 支払方法）
3. カバレッジをスライダーで設定（デフォルト: 80%）
4. 使用率をスライダーで設定（デフォルト: 80%）
5. （オプション）"割引率情報" アイコンをクリックして詳細を確認
6. "シミュレーション実行" ボタンをクリック
```

**入力制約:**
- カバレッジ: 0〜100%（整数）
- 使用率: 0〜100%（整数）
- カバレッジ = 0%の場合、警告を表示

### 3. シミュレーション実行機能

**機能ID**: `FR-003`  
**機能名**: リアルタイムコスト計算

**ユーザーストーリー:**
> 営業担当者として、設定したパラメータに基づいて、リアルタイムでコスト比較を実行したい。

**詳細機能:**
- ✅ **API呼び出し**: サーバー側でコスト計算を実行
- ✅ **ローディング表示**: 計算中はローディングインジケータを表示
- ✅ **エラーハンドリング**: エラー時はユーザーフレンドリーなメッセージを表示
- ✅ **結果の自動表示**: 計算完了後、自動的に結果を表示

**計算内容:**
1. **ベースラインコスト**: オンデマンド料金での月額コスト
2. **保険RI/SPコスト**: 保険料、割引率、返金見込みを考慮した月額コスト
3. **標準RI/SPコスト**: 初期費用、時間単価を考慮した月額実効コスト
4. **累積コスト**: 12ヶ月分の累積コスト推移
5. **損益分岐点**: オンデマンドと比較した損益分岐月

**API仕様:**
```
POST /api/simulate
Content-Type: application/json

Request Body:
{
  "insurance": "30d",
  "standard_term": "1y",
  "standard_option": "no_upfront",
  "coverage": 0.8,
  "usage": 0.8,
  "resources": [
    { "service": "ec2", "instance": "t3.large", "quantity": 10 }
  ]
}

Response:
{
  "baseline_cost": 7944.0,
  "insurance": { ... },
  "standard": { ... },
  "cumulative": { ... },
  "details": [ ... ]
}
```

### 5. 返金見込み計算機能

**機能ID**: `FR-005`  
**機能名**: カバレッジに基づく返金見込み算出

**ユーザーストーリー:**
> 営業担当者として、カバレッジを100%未満に設定した場合、未使用分の保険料が返金されることを顧客に説明したい。

**詳細機能:**
- ✅ **返金見込み計算**: 100%カバレッジ時の保険料 - 実際のカバレッジ時の保険料
- ✅ **返金見込み表示**: コストカード、詳細テーブルに返金見込みを表示
- ✅ **実効削減額**: 月額削減額 + 返金見込み = 実効削減額

**計算式:**
```
返金見込み = (オンデマンド時間単価 × 時間 × 全数量 × 割引率 × 保険料率)
           - (オンデマンド時間単価 × 時間 × カバレッジ数量 × 割引率 × 保険料率)
```

**表示例:**
```
カバレッジ: 80%
保険料: $793.44
返金見込み: $158.69
実効削減額: $2,441.09（= $2,282.40 + $158.69）
```
